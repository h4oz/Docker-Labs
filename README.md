# 🐳 DockerLabs Writeups

Repositorio donde documento las máquinas de **DockerLabs** que voy resolviendo durante mi aprendizaje de pentesting.

Los writeups incluyen reconocimiento, enumeración, explotación y escalada de privilegios, explicando el proceso paso a paso.

## 📚 Máquinas resueltas

| Máquina | Dificultad | Técnicas principales |
|---|---|---|
| [Bypassme](./Bypassme/) | 🟢 Fácil | SQLi, LFI, SSH, UNIX Socket, Cron Job |

| [HedgeHog](./HedgeHog/) | 🟢 Muy Fácil | Wordlists, Hydra, SSH, sudo, NOPASSWD |
